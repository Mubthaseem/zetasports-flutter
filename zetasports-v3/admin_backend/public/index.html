⚡ HEADLESS API GATEWAY ONLINE

ZetaSports Admin API Gateway v3

This is the decoupled, headless serverless backend for ZetaSports. UI access is strictly decoupled and hosted on the frontend client portal. 

GET  /api/auth/me           (Session verify)
POST /api/auth/google       (Google OIDC login)
POST /api/auth/logout       (Terminate session)
GET  /api/settings          (100 settings hub)
POST /api/settings          (Update & audit log)
GET  /api/blogger/config    (Blogger API status)
POST /api/blogger/publish   (Auto-post match)
GET  /api/fotmob/matches    (Live telemetry)
POST /api/thumbnail/render  (Canvas generator)
GET  /api/audit             (Immutable security)
Frontend Portal: zetasports-admin-portal.netlify.app →
